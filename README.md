# Wedding Invite

A single-page wedding invitation website: names, countdown, event schedule, venue map link and an RSVP form.

## Customise

Edit `config.js` — names, dates, events, venue, map link, RSVP deadline and RSVP email.

## Preview

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

## Publish

Push to GitHub and enable **Settings → Pages → Deploy from branch → `main` / root**.
